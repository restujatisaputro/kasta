# Runbook Operasional

Tambahkan runbook sebelum production untuk deployment/rollback, migration failure, backup/restore,
rotasi signing key, insiden kebocoran data tenant, kegagalan sinkronisasi, dan object storage.
Setiap runbook harus memuat pemicu, prasyarat, langkah verifikasi, langkah pemulihan, owner, dan
jalur eskalasi.
